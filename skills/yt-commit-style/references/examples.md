# Commit message examples

## Good

```
✨ feat(scripts): add publish-repo helper for bulk skill uploads

Publishing skills one by one was slow for repos with dozens of skills.

Reviewed-by: uc-skills-demo
```

```
🐛 fix(publish): skip symlinks when staging a skill bundle

Reviewed-by: uc-skills-demo
```

## Bad

- `Updated stuff.` — no type, no scope, past tense, trailing period
- `feat: Add new feature to the publishing script that handles many skills` — no emoji, no scope, too long, capitalized
